Start in three commands

First, install it and run setup.

npm install -g claude-autorouter
claude-autorouter setup

Setup uses your Claude subscription and the local Ollama evaluator, so it asks for no evaluator key. Add --pull to download the default model.

Then check that everything is healthy.

claude-autorouter doctor

Run doctor --evaluate-local to time the local evaluator on synthetic prompts. It makes no Anthropic or Jev calls and downloads nothing.

Finally, launch Claude Code through the gateway.

cd /path/to/project
claude-autorouter claude --permission-mode auto

Your installed, unmodified Claude Code opens with a temporary status line:

● AutoRouter · Opus 5.5 · ready · Jev 210ms

● AutoRouter · Sonnet 5.5 selected · Auto floor from Haiku · Jev 220ms

“Selected” means Anthropic has not reported the serving model yet.
